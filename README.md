# node-red-projects - Automation Projects Using Node-RED

During the development of automation projects, I came across Node-RED, which proved to be a very interesting tool for developing and integrating industrial automation systems. One of its main advantages is its ability to easily integrate different devices and systems, supporting several communication protocols and technologies commonly used in industry, such as MQTT, Modbus TCP, and OPC UA.

In addition to communicating with external equipment and systems, Node-RED also allows the creation of simulations and test environments, making it possible to reproduce different scenarios without the need to directly use physical equipment. The use of JavaScript functions also provides greater flexibility for developing logic, processing data, and creating customized scenarios.

Therefore, the projects presented in this repository explore Node-RED not only as a tool for supervision and communication, but also as a platform for developing, simulating, and integrating automation systems, enabling the connection between different technologies and facilitating the analysis of system behavior.
